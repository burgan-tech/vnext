# Agent Council Charter

## Purpose

The council selects the best-supported and verifiable approach before implementation. Consensus is not required; evidence and explicit dissent are preserved.

## Required Outputs

Each session records the problem and acceptance criteria, independent proposals, assumptions, objections and responses, selected approach, rejected alternatives, dissent, risks, verification and measurement plan, rollback plan, and Chair decision when required.

## Principles

1. Evidence comes before seniority or majority vote.
2. Security and data integrity are hard constraints.
3. Architecture quality and delivery cost are evaluated together.
4. Decisions must be observable and reversible where practical.
5. Agent roles keep different priorities visible; artificial consensus is prohibited.
6. Approved decisions and their evidence remain auditable.
7. The workflow/orchestrator owns session state; agents recommend transitions only.
