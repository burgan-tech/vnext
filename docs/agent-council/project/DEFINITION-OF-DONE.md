# Definition Of Done

A change is complete only when applicable items are evidenced:

- [ ] Acceptance criteria pass.
- [ ] Council decision and required Chair approval exist.
- [ ] Independent review is complete.
- [ ] Unit and required integration tests pass.
- [ ] API/event contracts are versioned and consumer impact is assessed.
- [ ] Security checks are complete.
- [ ] Performance baseline and comparison exist for sensitive changes.
- [ ] Logs, metrics, traces and audit needs are covered.
- [ ] Timeout, retry, idempotency, cancellation and concurrency are evaluated.
- [ ] Deployment and rollback steps are verified.
- [ ] Documentation and ADRs are updated where applicable.
- [ ] Accepted technical debt has an owner, rationale and due date.
- [ ] No blocking review or validation findings remain.
